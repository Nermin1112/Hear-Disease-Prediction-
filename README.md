# Heart Disease Prediction

## 📌 Project Overview
This project analyzes a dataset of patients to predict the presence of heart disease using machine learning models.

## 💡 Tools & Technologies
- Python (Pandas, NumPy, Scikit-learn, Seaborn, Matplotlib)
- Jupyter Notebook

## 📊 What I Did
- Data cleaning & preprocessing
- Exploratory Data Analysis (EDA)
- Trained and compared 4 classification models
- Used GridSearchCV for SVM optimization
- Visualized model performance

## 🔍 Key Results
- Best accuracy from: Random Forest Classifier
- SVM optimized using GridSearchCV
- Visualized metrics with seaborn

## 🚀 How to Run
1. Clone this repo
2. Open `heart_disease_project.ipynb` in Jupyter Notebook
3. Run all cells

## 📎 Dataset
Heart Disease Dataset from [Kaggle]
